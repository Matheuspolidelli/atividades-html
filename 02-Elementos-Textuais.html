Aprendendo Sobre Elementos Textuais

O que sao elementos textuais?

Os elementos textuais servem para destacar, enfatizar ou dar um significado a partes especificas do conteudo

Elementos strong

e muito Importante Aprender a estrutura do HTML

strong possui valor semantico, ou seja, ele da um significado ao conteudo que esta dentro dele

Elemento b

Aprenda HTML, css e javaScript para criar paginas web

A tag b( bold ) tambem costuma deixar o texto em negrito,mas sua finalidade e criar apenas um estilo/destaque visual.

O elemento b nao possui valor semantico, ou seja, ele nao da um significado ao conteudo que esta dentro dele

Elemento em

O termo realmente Precisa estudar

o elemento em comunica aquele trecho deve receber uma derteminada enfase dentro da frase.

Elemento i

O termo software e utilizado com frequencia na area de tecnologia

o elemento i possui a mesma formataçao visual que o elemento em, porem, nao possui valor semantico. E apenas estilo visual
