O que sao listas no html

uma lista e uma sequencia de itens relacionados entre si

No html existem principalmente tres tipos de listas listas nao ordenadas e listas de descriçao .

Listas nao ordenadas (ul)

uma lista nao ordenada e usada quando a ordem dos elementos ou itens nao importa

  • Arroz
  • Feijao
  • Macarrao
  • Carne
  • cafe

Listas ordenadas (ol)

Usamos uma lista ordenadaquando os itens possui uma sequencia uma classficaçao ou uma ordem que precisa ser respeitada.

  1. Acordar
  2. Tomar cafe
  3. Escovar os dentes
  4. Arrumar a cama
  5. Sair de casa

Listas de descrição (dl)

usamos uma lista de descriçao quando precisamos descrever algum termo

para criarmos essa lista utilizamos elementos

  • dl representa a lista de descriçao
  • dt representa o termo a ser descrito
  • dd representa a descrição do termo
